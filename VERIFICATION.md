# Проверка решения

Проверка выполнена 14 октября 2026 года. Основной запуск — локальное Linux-окружение с Python 3.12.

## Автоматическая проверка

В наборе 27 тестов. Один тест использует необязательный исходный Excel из переменной `BOOK_MONITOR_TEST_WORKBOOK`: без приложения он пропускается. Остальные тесты используют синтетические данные и mock API, не требуют ключей и не делают платных запросов.

Проверяется:

- сохранение исходных строк, стабильные ID и идемпотентность импорта;
- дубли, одинаковые названия у разных авторов, перестановка имени/фамилии;
- арабские и римские номера томов, книги в сборниках;
- аудио/ebook, исключение рекомендаций из признаков;
- CAPTCHA, вход, загрузочная оболочка, сетевые ошибки и повторы;
- ограничения внутренних URL, Host/Origin и CSV formula injection;
- бюджет AI, некорректный JSON, кэш одинаковых параллельных запросов;
- экспорт только выбранных строк и страницы журнала за пределами 200 событий;
- корректное завершение уже закрытого браузера.

Локальный прогон с оригинальным приложением: **27 passed**. Ожидаемый прогон без него: **26 passed, 1 skipped**.

### Дополнение: объединения и варианты автора

Добавлены семь тестов группировки. Актуальный набор: **34 теста** (без оригинального приложения — **33 passed, 1 skipped**). Проверяются одна карточка для точных дублей, подтверждение трёх вариантов автора, сохранение исходных значений, снятие текущей неоднозначности, повторный импорт, отмена объединения, конфликты томов, защита эталонных ID, отклонение предложений и CSV с основными полями. Отдельный тест проводит проверку страницы с подтверждённым псевдонимом и получает статус 1 без AI, сохраняя основную карточку книги и использованный вариант.

### Дополнение: автоматический AI-разбор карточек

Добавлены 12 тестов: автоматическое объединение опечаток, использование вариантов в сопоставлении, неизменность исходных ячеек, отсутствие повторных запросов при повторном импорте, защита отменённых / вручную отклонённых связей, отказ от объединения разных авторов по одному названию, проверка цитат и отрицательных утверждений, автоматическое разделение, продолжение работы при исчерпании бюджета и ожидание завершения группировки обработчиками страниц. Актуальный набор: **46 тестов**, без оригинального приложения — **45 passed, 1 skipped**.

На вымышленных данных выполнен вызов `gpt-4.1-mini` через AI Tunnel: модель определила опечатку в фамилии, код объединил три исходные строки в одну карточку. Стоимость вызова — **0,06 ₽**; повторная оценка использовала кэш без нового расхода. Это интеграционная проверка, а не оценка точности на независимой выборке.

## Реальные страницы

Исходное приложение содержит 150 строк первой части и 10 URL второй. Импорт сохранил 160 строк, сформировал 101 предварительную запись книги, отметил 13 групп повторных URL и два неоднозначных названия. Оригинальный файл не изменялся и в публичный репозиторий не включён.

Десять URL второй части проверены через HTTP, PDF и Playwright. После исправлений: **6 статусов 1, 1 статус 0, 3 статуса 2**. Два подтверждённых размещения оказались аудиокнигами, хотя исходный формат ebook. Один PDF оказался другой книгой. Целевая книга в сборнике определена по явному перечню его содержимого. Неопределённые случаи оставлены без принудительного решения: 403, незагрузившееся содержимое JavaScript и недостаток доказательств автора/размещения.

Основная модель реально вызывалась через AI Tunnel. Проверена отдельная vision-диагностика снимка; её ответ не отменяет техническую ошибку доступа.

## Интерфейс

Через Playwright проверены загрузка, фильтр аудиокниг, выбор двух результатов и CSV-экспорт выбранных строк; переход между страницами 160 исходных записей и журнала. Подробности раскрывают исходную строку, книгу, причины и признаки. Скриншот в README содержит вымышленные данные, а не данные пользователя.

## Что не подтверждено

Docker-конфигурация подготовлена, но контейнерный запуск не проверялся. Полнота универсального парсинга и точность сопоставления на независимом размеченном наборе не измерены. Эталонный каталог в исходном приложении отсутствует. Автоматическое прохождение CAPTCHA, регистрация, OCR сканов и распределённая очередь не реализованы; эти ограничения указаны в README.
